## 🔧 Advanced Features

### Custom Selectors

Create powerful custom selectors for any website:

```javascript
{
  \"name\": \"product_price\",
  \"selector\": \".price, [data-price], .cost\",
  \"type\": \"text\"
}
```

**Selector Types**:
- `text` - Extract text content
- `attribute` - Extract HTML attributes (href, src, etc.)
- `html` - Extract raw HTML

**Pro Tips**:
- Use multiple selectors separated by commas
- Use browser DevTools to find selectors
- Test selectors with Quick Scrape first

### API Integration

Access CRAWLai programmatically:

#### Quick Scrape
```bash
curl -X POST {API_URL}/api/scrape/quick \\
  -H \"Content-Type: application/json\" \\
  -d '{
    \"url\": \"https://example.com\",
    \"selectors\": [],
    \"extract_links\": true,
    \"extract_images\": true,
    \"extract_tables\": true
  }'
```

#### Create Project
```bash
curl -X POST {API_URL}/api/projects \\
  -H \"Content-Type: application/json\" \\
  -d '{
    \"name\": \"My Project\",
    \"description\": \"Description here\",
    \"target_url\": \"https://example.com\",
    \"selectors\": []
  }'
```

#### Run Project
```bash
curl -X POST {API_URL}/api/projects/{project_id}/run
```

#### Get Results
```bash
curl {API_URL}/api/projects/{project_id}/results
```

#### Get Statistics
```bash
curl {API_URL}/api/stats
```
